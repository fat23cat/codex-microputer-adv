# Micro5 digit source

Micro5 is retained only to regenerate the embedded `1`–`6` bitmaps with
`tools/generate_micro5_digits.py`. It is distributed under SIL Open Font
License 1.1; its license is stored beside the font.

- Micro 5 — https://github.com/google/fonts

The generated glyphs are 20×28 maximum, monochrome and rendered at their final
LCD size. The firmware does not scale or antialias them at runtime.
